## 1. EXECUTIVE SUMMARY & WHAT IS AURAMINATOR?

**AURAMINATOR (auraminator.in)** is an elite, multi-sided marketplace, protected escrow deal, and career platform built for the modern creator, developer, and startup economy. 

It combines **7 distinct commercial engines** with a zero-leakage **Anti-Circumvention & Escrow Protection Protocol**:
1. **Turnkey SaaS Platforms & Revenue Websites**: Buying and selling revenue-generating web apps with verified Stripe MRR/ARR, domain EPP auth codes, and database transfers.
2. **Mobile Apps (iOS & Android)**: Buying and selling published apps with verified store downloads, in-app purchases, and Apple App Store / Google Play Console zero-downtime transfers.
3. **Full Source Code & IP Repositories**: Commercial source code and 100% exclusive copyright assignment with private GitHub organization handovers.
4. **Social Media Accounts & Digital Real Estate**: Monetized YouTube channels, high-engagement Instagram pages, X/Twitter handles with verified follower metrics and original registration email (OGE) handovers.
5. **Physical Luxury Streetwear & Apparel**: Architectural cut-and-sew heavyweight drops (500 GSM French Terry) with automated Shiprocket logistics (Delhivery/BlueDart).
6. **Online Tech Services & No-Contact Sprints**: Emergency 24h debugging, Next.js architecture sprints, and smart contract audits with post-payment direct WhatsApp/Call unlock and GitHub Pull Request delivery.
7. **100% Free Creator & Tech Job Board**: Startups post jobs for free, talent applies with 1-click rich dossiers (Resumes, GitHub, Portfolios), and hiring teams manage candidate pipelines.

  * Once the developer submits the verified GitHub PR / deliverable link and the buyer approves, **85% payout is released to the seller** and **15% platform commission** is retained.

- **15% Platform Commission**: On every completed SaaS deal, mobile app transfer, source code sale, social account handover, digital vault download, or tech service sprint, **Auraminator automatically retains 15%** as platform revenue.
- **85% Net Seller Payout**: The seller receives 85% directly deposited into their linked bank account via Razorpay Route.

---

### Persona B: The Buyer / Asset Investor / Tech Collector
- **Goal**: Buy SaaS, mobile apps, source code, social accounts, luxury streetwear, or hire tech services safely.
- **How it works (Step-by-Step)**:
  1. **Discovery**: Finds an asset on `/explore` (e.g. *VividAI SaaS generating ₹48.5k/mo MRR*).
  2. **Option 1 (Instant Buy at List Price)**: Clicks "BUY NOW", pays through Razorpay Route, and locks funds into escrow.
  3. **Option 2 (Make an Offer & Negotiate)**: Clicks **"MAKE AN OFFER"**, types custom price (e.g. ₹3,80,000) and terms (e.g. *"Includes 30 days developer support"*).
  4. **Negotiation Room (`/deals/[id]`)**: Seller counters or accepts. Once agreed, buyer deposits funds into Auraminator Escrow.
  5. **48-Hour Inspection Window**: Seller deposits Domain EPP codes, GitHub repo invites, and Stripe credentials in the encrypted handover vault. A 48-hour inspection timer starts.
  6. **Escrow Release**: Buyer verifies DNS propagation and Stripe access, then clicks **"Confirm Handover & Release Escrow"**. Funds clear to seller.

- **Goal**: Monetize apps, websites, source code, digital files, tech services, or streetwear drops.

  3. **Manage Negotiations (`/account/deals`)**: Receives real-time offers from buyers. Can accept, reject, or submit counter-offers with notes.
  4. **Credential Handover (`/deals/[id]`)**: Once buyer deposits escrow, seller deposits domain auth codes, GitHub invites, or social tokens into the encrypted handover vault.
  5. **Automated Payout**: When buyer approves or inspection window expires without dispute, 85% net payout is automatically credited to the seller's bank account.

## 5. BACKEND ENGINE ARCHITECTURE & SECURITY

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                AURAMINATOR BACKEND ENGINES                             │
├──────────────────────────┬──────────────────────────┬──────────────────────────────────┤
│    POSTGRESQL & RPCs     │      RAZORPAY ROUTE      │         CLOUDFLARE R2            │
│  Supabase PostgreSQL DB  │  Automated Split Escrow  │  Zero-Trust Asset Storage        │
│  Atomic 15m stock locks  │  85% Seller / 15% Platform│  Presigned short-lived download  │
│  Strict Row-Level (RLS)  │  HMAC SHA-256 Webhooks   │  SSRF-protected URL ingestion    │
├──────────────────────────┼──────────────────────────┼──────────────────────────────────┤
│        SHIPROCKET        │     GOOGLE GEMINI AI     │         NEXT.JS 14 EDGE          │
│  Delhivery / BlueDart    │  Listing optimization    │  Sub-50ms SSR & Edge routing     │
│  Automated AWB labels    │  Smart search & Copilot  │  Google Search Console verified  │
│  Delivery scan webhooks  │  SEO metadata drafting   │  100% Strict TypeScript safety   │
└──────────────────────────┴──────────────────────────┴──────────────────────────────────┘
```

### 1. The Protected Deal & Negotiation State Machine
- **States**: `pending` ➔ `countered` ➔ `accepted` ➔ `awaiting_deposit` ➔ `escrow_locked` ➔ `credentials_transferred` ➔ `buyer_inspecting` (48h timer) ➔ `completed_paid` / `disputed`.
- **Zero Off-Platform Leakage**: Domain EPP codes, GitHub organization invites, and Stripe customer transfers happen inside the encrypted deal room.
- **Double-Entry Ledger**: Platform fee (15%) and seller payout (85%) are immutably written into the `escrow_ledger` table.

### 2. High-Concurrency Streetwear Concurrency Locking
- **15-Minute Atomic Lock**: When a buyer adds a limited physical drop to their cart, a PostgreSQL RPC `reserve_inventory` places an atomic lock with a 15-minute expiration timestamp.
- **Zero Overselling**: If another buyer tries to purchase the last unit, the database rejects the reservation atomically.

### 3. Automated Courier Dispatch & Delivery Webhooks
- **1-Click AWB**: Seller clicks "Dispatch via Shiprocket" -> API generates tracking AWB via Delhivery Express or BlueDart.
- **Auto-Release Trigger**: When the courier scans the parcel as "Delivered", Shiprocket fires an authenticated webhook to `/api/webhooks/shiprocket`, which unlocks the creator's escrow funds automatically.

### 4. Zero-Trust Digital Vault & SSRF-Protected Ingestion
- **Presigned URLs**: Buyers never receive direct public S3 URLs. Downloads are issued via cryptographic HMAC tokens with 15-minute expiration and 50-download rate limits.
- **SSRF Ingestion Defense**: When sellers import files via external URLs, Auraminator validates IP ranges (blocking loopbacks `127.0.0.1`, `169.254.169.254`, and private subnets) before streaming to Cloudflare R2.

### Step 1: Initialize Supabase Database & Unified Storage (5 Minutes)
1. Create a free project on [supabase.com](https://supabase.com).
2. Open **SQL Editor**, paste the contents of `supabase/schema.sql`, and click **Run**.
   *(This automatically creates all database tables, RLS policies, and the `digital-vaults` storage bucket with zero extra cost).*
3. Copy `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, and `SUPABASE_SERVICE_ROLE_KEY`.
4. *(Optional Google Login)*: In Supabase Dashboard -> **Authentication -> Providers -> Google**, paste your Google Client ID and Secret from Google Cloud Console.

### Step 2: Connect Razorpay Route & Escrow (10 Minutes)
1. Log in to [razorpay.com](https://razorpay.com) and complete business KYC.
2. In **Settings -> API Keys**, generate **Live Key ID** and **Live Key Secret**.
3. Enable **Razorpay Route** in settings for multi-vendor split commerce.
4. In **Settings -> Webhooks**, add:
   * **URL**: `https://auraminator.in/api/webhooks/payments`
   * **Secret**: Your webhook secret string (e.g. `aura_live_secret_9921`)
   * **Events**: `payment.captured`, `order.paid`

### Step 3: Connect Shiprocket Courier Logistics (5 Minutes)
1. Create account on [shiprocket.in](https://app.shiprocket.in).
2. Add your primary warehouse pickup address in **Settings -> Pickup Address**.
3. In **Settings -> API -> API Users**, generate API credentials and note your `SHIPROCKET_EMAIL` and `SHIPROCKET_PASSWORD`.
4. Set Shiprocket Webhook URL to `https://auraminator.in/api/webhooks/shiprocket`.

### Step 4: Deploy on Vercel & Connect Domain (5 Minutes)
1. Push codebase to your GitHub repository:
   ```bash
   git add .
   git commit -m "feat: launch auraminator master commerce & escrow deal engine"
   git push origin main
   ```
2. In [vercel.com](https://vercel.com), click **Import Project** -> select your repo.
3. Paste keys into Vercel **Environment Variables** (see below).
4. Connect domain `auraminator.in` and `www.auraminator.in` (DNS: A Record pointing to `76.76.21.21`).
